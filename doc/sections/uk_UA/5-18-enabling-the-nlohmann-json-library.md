## Вмикання інтеграції бібліотеки nlohmann JSON

Бібліотека [nlohmann JSON](https://github.com/nlohmann/json.git) читає файли ваг нейромереж dxxwjz1 (стиснені gzip документи JSON, див. секцію [Файли ваг нейромереж](/doc/sections/uk_UA/4-7-4-network-weights-files.md)), тому проект її потребує, і CMake змінна `ENABLE_NLOHMANN_JSON` за замовчуванням має значення `ON`. Якщо встановлену системну бібліотеку знайдено (пакет `nlohmann-json3-dev` у Debian і Ubuntu), використовується вона, інакше під час конфігурації з мережі завантажується її випуск `v3.11.3` (кеш-змінні `DARKNETXX_NLOHMANN_GIT` і `DARKNETXX_NLOHMANN_GIT_TAG` задають репозиторій і тег). Вимкнути змінну неможливо: конфігурація повертає їй значення `ON` з попередженням, зокрема й у директоріях побудови, сконфігурованих попередніми версіями проекту, кеш яких зберігає типове для них значення `OFF`.

```
# в середині кореневої директорії проекту

cmake -S . -B build -DENABLE_NLOHMANN_JSON=ON
```
