## Вмикання підтримки генерування DEB-пакетів з cpack

Для того щоб мати змогу згенерувати `deb`-пакет необіхдно сконфігурувати проект для підтримки команди `cpack` за допомогою змінної `ENABLE_DEB`:

```
# всередині кореневої директорії проекту 

mkdir -vp build && cd build && cmake ../ -DENABLE_DEB=ON
```

Наступним кроком буде збирання або компіляція усіх необхідних файлів які повинні входити у `deb`-пакет:

```
# всередині директорії побудови проекту-шаблону

cmake --build . --target all
```

На кінець, необіхдно виконати команду `cpack` всередині директорії побудови проекту-шаблону:

```
# всередині директорії побудови проекту-шаблону

cpack
```

Згенерований пакет повинен згенеруватись всередині кореня директорії побудови проекту. Наприклад, якщо ім'я проекту було не зміненим і його версія 0.8.0 тоді назва пакету може виглядати наступним чином: `darknetxx-0.8.0-Linux.deb`.

Для того щоб переглянути або змінити параметри створення `deb`-пакетів необхідно відвідати файл `cmake/darknetxx-deb-enabler.cmake`.

### Бібліотека darknetxx-datadrivers у пакеті

Бібліотека [darknetxx-datadrivers](https://github.com/yuriysydor1991/darknetxx-datadrivers), з якою лінкуються бінарні файли (див. секцію [Вмикання бібліотеки darknetxx-datadrivers](/doc/sections/uk_UA/5-39-enabling-the-darknetxx-datadrivers-library.md)), не є пакетом дистрибутива, тож сканування `dpkg-shlibdeps` пакета не знаходить пакета, від якого можна залежати, і сам пакет запускався б лише в системі, де бібліотеку вже встановлено. Опція `ENABLE_DEB_DARKNETXX_DATA_DRIVERS`, за замовчуванням `ON`, натомість пакує бібліотеку в пакет: той самий спільний об'єкт, на який вказує знайдений пакет CMake бібліотеки, разом з його посиланням soname потрапляє в директорію `lib`, у яку проект встановлює власну бібліотеку, тож пакет повний сам по собі - так само, як проект ImagesAnnotator пакує власні бібліотеки даних. Це правило встановлення директорії побудови, тож `cmake --install` побудови, сконфігурованої так, теж копіює бібліотеку. Бінарний файл `darknetxxConverter` бібліотеки не пакується: він постачається з пакетами самої бібліотеки (див. секцію [Бінарний файл darknetxxConverter](/doc/sections/uk_UA/5-35-the-darknetxxConverter-binary.md)).

```
# в середині кореневої директорії проекту

# пакет без бібліотеки darknetxx-datadrivers для систем, у яких її встановлено
cmake -B build -S . -DENABLE_DEB=ON -DENABLE_DEB_DARKNETXX_DATA_DRIVERS=OFF
```

| Опція CMake | За замовчуванням | Дія |
| --- | --- | --- |
| `ENABLE_DEB_DARKNETXX_DATA_DRIVERS` | `ON` | Пакує в пакет `deb` спільний об'єкт бібліотеки darknetxx-datadrivers, з якою лінкуються бінарні файли. |
