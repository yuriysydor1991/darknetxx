# Доступні параметри командного рядка

Згенерований виконуваний файл приймає набір параметрів командного рядка, які розпізнаються класом `CommandLineParser` і описуються класом `ApplicationHelpPrinter`. Завжди актуальний перелік, що підтримується поточною побудовою, можна надрукувати у будь-який момент за допомогою прапорця `--help` (або `-h`):

```
# з директорії побудови
./src/darknetxx --help
```

Нижче параметри згруповані за їхнім призначенням. Параметри зі значенням-заповнювачем (наприклад, `<N>` або `<FILE>`) очікують, що це значення буде вказано одразу після прапорця, наприклад `--threads 4`. Прапорці без заповнювача є перемикачами і не приймають значення. Передача невідомого параметра друкує цю довідку і зупиняє виконання.

## Загальні параметри

| Параметр | Значення | Опис |
| --- | --- | --- |
| `--help`, `-h` | | надрукувати довідкове повідомлення і вийти |
| `--version`, `-v` | | надрукувати версію програми, git коміт побудови і дату конфігурації, після чого вийти |
| `--log-file`, `-l` | `<FILE>` | записувати журнал програми у вказаний файл |

## Параметри мережі і моделі

| Параметр | Значення | Опис |
| --- | --- | --- |
| `--train-cfg` | `<FILE>` | файл конфігурації навчальної мережі (`*.cfg`) |
| `--detect-cfg` | `<FILE>` | файл конфігурації мережі розпізнавання (`*.cfg`) |
| `--names` | `<FILE>` | файл назв класів (має перевагу над ключем `names=` секції `[net]` конфігурації) |
| `--weights` | `<FILE>` | файл ваг мережі для завантаження |
| `--image` | `<FILE>` | файл зображення для виконання розпізнавання |
| `--gpus` | `<LIST>` | розділений комами список індексів GPU для використання |
| `--threads` | `<N>` | кількість робочих потоків для використання |

## Параметри конвертування файлів ваг нейромереж

Перші чотири параметри вказуються разом і конвертують файл ваг нейромережі без запуску навчання чи розпізнавання, дивись секцію [Конвертування файлів ваг нейромереж](/doc/sections/uk_UA/6-2-4-converting-the-network-weights-files.md).

| Параметр | Значення | Опис |
| --- | --- | --- |
| `--convert-from` | `<FORMAT>` | формат файлу ваг нейромережі для читання: `weights` або `dxxwjz1` |
| `--convert-src` | `<FILE>` | файл ваг нейромережі для читання |
| `--convert-to` | `<FORMAT>` | формат файлу ваг нейромережі для запису: `weights` або `dxxwjz1` |
| `--convert-dst` | `<FILE>` | файл ваг нейромережі для запису (замінюється) |
| `--convert-cfg` | `<FILE>` | файл cfg нейромережі, якій належать ваги: обов'язковий для читання формату `weights`, а файл формату `dxxwjz1` перевіряється на відповідність йому |

## Параметри навчання

| Параметр | Значення | Опис |
| --- | --- | --- |
| `--clear` | | очистити (скинути) лічильники ітерацій навчання |
| `--map` | | обчислювати mAP під час навчання |
| `--mAP-epochs` | `<N>` | обчислювати mAP кожну задану кількість епох (за замовчуванням 4) |
| `--dont-resize-network` | | не змінювати розмір мережі під час навчання |
| `--net-resize-nth` | `<N>` | змінювати розмір мережі кожну N-ту ітерацію навчання (за замовчуванням 10) |
| `--data-reload-nth` | `<N>` | завантажувати новий навчальний пакет лише кожну N-ту ітерацію, повторно використовуючи його між ними (має перевагу над прапорцем нижче) |
| `--dont-reload-data-every-iteration` | | продовжувати навчання на завантаженому пакеті замість завантаження нового на кожній ітерації (зміна розміру мережі все одно його перезавантажує) |
| `--stop-less-avg-loss` | `<VALUE>` | зупинити навчання щойно середня втрата досягне заданого значення або менше |
| `--chart-path` | `<FILE>` | шлях для збереження графіка навчання |
| `--save-charts-every-iter` | | зберігати графік навчання на кожній ітерації, а не кожні 100 |
| `--dont-save-charts-every-iter` | | зберігати графік навчання кожні 100 ітерацій (за замовчуванням) |
| `--draw-precision` | | малювати криву mAP на кожній ітерації після її обчислення, а не лише під час обчислень |

## Параметри розпізнавання і виводу

| Параметр | Значення | Опис |
| --- | --- | --- |
| `--thresh` | `<VALUE>` | поріг впевненості розпізнавання (за замовчуванням 0.25) |
| `--iou-thresh` | `<VALUE>` | поріг перетину над об'єднанням, IoU (за замовчуванням 0.5) |
| `--hier` | `<VALUE>` | ієрархічний поріг розпізнавання (за замовчуванням 0.5) |
| `--points` | `<N>` | кількість точок відгуку при обчисленні mAP під час навчання (`101` для MS COCO, `11` для PascalVOC 2007, `0` для площі під кривою) |
| `--letter-box` | | змінювати розмір зображення зі збереженням пропорцій (letter box) |
| `--ext-output` | | друкувати розширений вивід з координатами обмежувальних рамок |
| `--save-labels` | | зберігати розпізнані мітки |
| `--out` | `<FILE>` | файл для запису результатів |
| `--benchmark` | | виміряти продуктивність розпізнавання (передбачає `--dont-show`) |
| `--benchmark-layers` | | виміряти продуктивність кожного шару мережі (лише для побудов з GPU) |

## Параметри вікон

| Параметр | Значення | Опис |
| --- | --- | --- |
| `--show` | | показувати вікна графічного інтерфейсу (увімкнено за замовчуванням, скасовує `--dont-show`) |
| `--dont-show` | | не показувати вікна графічного інтерфейсу |
| `--show-imgs` | | показувати аугментовані навчальні зображення |

## Ще не підтримувані параметри

Параметри режимів відеодемонстрації, трансляції результатів та обчислення якорів оригінального Darknet, коду яких `darknetxx` поки не має. Вони зарезервовані й відхиляються з помилкою, якщо їх вказано, замість того щоб мовчки ігноруватись.

| Параметр | Значення | Оригінальне призначення |
| --- | --- | --- |
| `--width`, `--height` | `<N>` | розмір входу для обчислення якорів |
| `--num-of-clusters` | `<N>` | кількість кластерів якорів |
| `--prefix` | `<PREFIX>` | префікс збережених кадрів відео |
| `--out-filename` | `<FILE>` | вихідний файл відео |
| `--dontdraw-bbox` | | без обмежувальних рамок на кадрах відео |
| `--cam-index` | `<N>` | камера (вебкамера) для захоплення |
| `--frame-skip` | `<N>` | кількість кадрів, що пропускаються між розпізнаваннями |
| `--avg-frames` | `<N>` | кількість кадрів для усереднення розпізнавань |
| `--time-limit-sec` | `<SEC>` | обмеження часу обробки відео |
| `--mjpeg-port` | `<PORT>` | порт для трансляції результату MJPEG |
| `--json-port` | `<PORT>` | порт для трансляції результату JSON |
| `--http-post-host` | `<HOST>` | хост для надсилання результатів HTTP POST |
| `--json-file-output` | `<FILE>` | файл для запису результатів відео у форматі JSON |

## Файли даних конфігурації мережі

Оригінальний Darknet брав назви класів, списки зображень для навчання і перевірки та директорію резервних копій з окремого файлу `*.data`. Натомість `darknetxx` читає їх з секції `[net]` файлу конфігурації мережі (`*.cfg`):

| Ключ | За замовчуванням | Опис |
| --- | --- | --- |
| `names=` | `data/names.list` | файл назв класів, по одній назві в рядку |
| `train=` | `data/train.txt` | список зображень для навчання |
| `valid=` | значення `train=` | список зображень для перевірки під час обчислення mAP (`--map`) |
| `backup=` | `backup` | директорія для збереження навчених ваг |

Відносні шляхи обчислюються відносно поточної робочої директорії. Параметр командного рядка `--names` має перевагу над ключем `names=`, тож стандартний файл конфігурації можна використовувати для розпізнавання без змін, наприклад:

```
darknetxx --detect-cfg yolov4.cfg --weights yolov4.weights --names coco.names --image dog.jpg
```

Для впровадження власного нового параметра командного рядка дивись секцію [Компоненти виконання програми](/doc/sections/uk_UA/4-7-1-application-runtime-components.md).
