## Необов'язкові пакети для форматування коду

Для підтримки автоматичного форматування коду за допомогою наявної CMake-цілі `clang-format` відповідний інструмент `clang-format` повинен бути встановленим наступною командою (для GNU/Linux систем):

```
sudo apt install -y clang-format
```

Стиль коду проекту потребує `clang-format` версії 16 або новішої. На системах, які постачають старішу версію за замовчуванням, слід встановити пакет з номером версії, наприклад `clang-format-16`, — ціль `clang-format` знаходить його за назвою.

Переглянь деталі конфігурації у секції [Вмикання підтримки форматування коду](/doc/sections/uk_UA/5-6-enabling-and-performing-code-formatting-target.md).
