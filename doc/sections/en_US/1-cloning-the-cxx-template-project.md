# Cloning the C++ template project

In order to fast-start implementing a new application clone this project into your local directory by executing next command in the terminal (GNU/Linux based):

```
git clone https://github.com/yuriysydor1991/darknetxx.git
```

or 

```
git clone https://gitlab.com/yuriysydor1991/darknetxx.git
```

After this command executes you should find a directory named `darknetxx` inside your current one. So enter it by calling `cd darknetxx`.
